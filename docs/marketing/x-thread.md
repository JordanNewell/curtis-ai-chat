**3/8 — BYOK / providers** (~255 chars)

Bring your own keys. 30 providers built in — Anthropic, OpenAI, Gemini, OpenRouter, Groq, DeepSeek, xAI, Mistral, Perplexity — plus any OpenAI-compatible endpoint as a custom provider. Keys go in your OS keychain, not a config file you sync by accident.

**4/8 — Local models** (~205 chars)

My favorite setup: Ollama on localhost. No API key, no cloud, nothing leaves the machine. LM Studio works the same, and semantic vault search can run on local embeddings too. Private notes stay private.

**5/8 — Agent mode** (~185 chars)

Agent mode (opt-in) reads, searches, creates, and edits notes — 11 built-in tools, plus any MCP server you already run. Point it at a messy folder, ask for a summary note, watch it work.

**6/8 — Vault-native + memory** (~200 chars)

Everything stays markdown. Chats save into your vault as notes. Memory is a file you can open and edit — and the model asks before saving anything about you. @-mention any note to attach it as context.
