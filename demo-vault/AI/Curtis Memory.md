# Curtis Memory

Facts Curtis remembers about the user across conversations. Pre-staged for demo purposes — feel free to edit or delete any of these via Settings → Memory.

This file is intentionally persona-agnostic so any demo conversation has reasonable context to draw on. For persona-specific memory, edit this file before the demo session to match the folder you're showing.

## Preferences

- Prefers terse responses. No filler, no preamble. Lead with the answer.
- Uses active voice, present tense for established facts.
- Bullet points over paragraphs when listing 3+ items.
- Cites numbers with sources, not vibes.

## Working style

- Decides and moves. Tolerates reversible mistakes over slow consensus.
- Reads widely across operators, engineers, writers, investors.
- Skeptical of advice from people who haven't built the thing.
- Believes constraints produce better work than freedom does.

## Tools

- Daily driver: Obsidian with Curtis AI Chat for thinking, drafting, and agent work
- Code: VS Code + Claude Code for software work
- Comms: Signal for sensitive, Slack for teams, email for async formal

## Current focus

- Shipping software in public
- Skeptical of "AI for X" framing — prefers "X, now with AI as one of the tools"
- Curious about how voice + agent tools change solo-operator velocity

## Standing instructions

- When asked to summarize, lead with the single most important point.
- When asked to draft, write the first pass without asking for clarification. Iterate after.
- When asked to decide between options, give a recommendation with a reason, not a list of tradeoffs.
- Use the user's own notes (via @-mention or agent tools) as the source of truth before reaching for general knowledge.
